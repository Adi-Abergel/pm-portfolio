Background Pattern Reference

Decorative geometric overlay options for the Hero section background. Each pattern is pure CSS — no images — layered semi-transparently over the existing gradient + photo background. Previews simulate the green gradient; the real page will show these patterns over the actual background image.

Options A – D
Option A
Side Column Grid
Vertical grid lines (with faint horizontal cross-lines) on the left and right thirds only, masked to zero toward the center. Frames the content like curtain columns without touching it.
/* ::before | position: absolute inset-0 */ background-image: repeating-linear-gradient(90deg, rgba(190,173,137,0.14) 0px 1px, transparent 1px 28px), repeating-linear-gradient(0deg, rgba(190,173,137,0.05) 0px 1px, transparent 1px 56px); mask-image: linear-gradient(90deg, black 0% 18%, transparent 36% 64%, black 82% 100%);
Option B
Fine Mesh
A uniform 24 px grid across the entire surface. So subtle it reads as texture rather than pattern — like laid paper. Works with any content placement and requires no masking.
/* ::before | position: absolute inset-0 */ background-image: repeating-linear-gradient(90deg, rgba(248,241,221,0.065) 0px 1px, transparent 1px 24px), repeating-linear-gradient(0deg, rgba(248,241,221,0.065) 0px 1px, transparent 1px 24px);
Option C
Diagonal Hatching (Sides)
45° diagonal lines confined to the left and right edges, fading inward. More energetic than vertical columns — suggests motion or depth while still leaving the center completely clear.
/* ::before | position: absolute inset-0 */ background-image: repeating-linear-gradient(45deg, rgba(190,173,137,0.11) 0px 1px, transparent 1px 22px); mask-image: linear-gradient(90deg, black 0% 16%, transparent 34% 66%, black 84% 100%);
Option D
Blueprint Two-Level Grid
Minor lines every 20 px + bolder major lines every 100 px, tinted sage-green. Feels like engineering graph paper or an architectural schematic — structured and precise.
/* ::before | position: absolute inset-0 */ background-image: repeating-linear-gradient(90deg, rgba(180,215,195,0.045) 0px 1px, transparent 1px 20px), repeating-linear-gradient(0deg, rgba(180,215,195,0.045) 0px 1px, transparent 1px 20px), repeating-linear-gradient(90deg, rgba(180,215,195,0.13) 0px 1px, transparent 1px 100px), repeating-linear-gradient(0deg, rgba(180,215,195,0.13) 0px 1px, transparent 1px 100px);
Option E
Option E
Diamond Crosshatch
Both +45° and −45° lines crossing to form a diamond / woven pattern across the full surface. Even and meditative — reads like a subtle fabric weave or an Art Deco screen. The gold tint ties it to the existing palette.
/* ::before | position: absolute inset-0 */ background-image: repeating-linear-gradient(45deg, rgba(190,173,137,0.075) 0px 1px, transparent 1px 36px), repeating-linear-gradient(-45deg, rgba(190,173,137,0.075) 0px 1px, transparent 1px 36px);
Implementation Note

All patterns are applied via a <div> (or ::before pseudo-element) inside the Hero <section>, with position: absolute; inset: 0; pointer-events: none; z-index: 1. The existing content wrapper stays at z-index: 10. No images needed — pure CSS gradients only. Options A and C use mask-image (supported in all modern browsers) to restrict the pattern to the edges. Options B, D, and E cover the full surface but are faint enough to be invisible behind the background photo.

Patterns can also be combined — for example, B (fine mesh) layered under A (side columns) gives a grid texture everywhere with stronger vertical framing at the edges.
