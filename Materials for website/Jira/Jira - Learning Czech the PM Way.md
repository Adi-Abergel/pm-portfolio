# Jira – Learning Czech the PM Way

## Overview
A personal Jira space built as a portfolio piece, framing Czech language learning as a structured product initiative. Tracks progress through the textbook *Česky krok za krokem* using Scrum methodology, with a 2-year goal of reaching A2 fluency and passing the permanent residency test.

- **Project Name:** Learning Czech- the PM way
- **Type:** Scrum (company-managed)
- **Tool:** Jira (Atlassian)
- **Built:** March 2026

## Board Columns

The sprint board uses 4 custom columns:
1. **In Progress** — actively being worked on
2. **Actively Learning** — currently studying the topic
3. **Practice** — topic learned, now in practice/review phase
4. **Done** — completed
