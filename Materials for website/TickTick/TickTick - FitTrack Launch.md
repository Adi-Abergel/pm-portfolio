# TickTick – FitTrack Launch

## Overview
A mock TickTick project to complement the Notion FitTrack workspace. Simulates how a PM would use TickTick for day-to-day task management alongside a broader project board.

- **Project Name:** 🚀 FitTrack Launch
- **Tool:** TickTick (personal workspace)
- **Snapshot Date:** March 21, 2025 (Week after Dev Sprint Review)
- **Current Phase:** Phase 3 — Development (In Progress)

## Portfolio Context

This TickTick setup demonstrates:
- **Daily task triage** — standup list as a living agenda
- **Priority management** — High/Medium/Low flags across active tasks
- **Weekly scoping** — "This Week" list as a lightweight sprint board
- **Backlog grooming** — future tasks ordered by rough timeline
- **Tool complementarity** — TickTick handles day-to-day execution while Notion holds the source of truth
